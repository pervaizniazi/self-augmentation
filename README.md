1. This is the code repository for the paper: Improving Text Representation for Disease Detection from Social Media via Self-augmentation and Contrastive Learning published at International Conference on Neural Information Processing, 137-151.
2. train.py contains code for training RHMD and Dreaddit datasets.
3. test.py contains code for evaluating RHMD and Dreaddit datasets.
4. train-depressionEmo.py contains code for training depressionEmo dataset.
